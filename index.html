Diagnóstico Territorial ZMG

La Crisis de Agua Turbia en Guadalajara

Evidencia técnica, periodística y comunitaria respalda la necesidad de monitoreo ciudadano con trazabilidad digital.

Agua Turbia y Sedimentos

Colonias en Zapopan, Guadalajara, Tlaquepaque y Tonalá reportan descargas periódicas con alta turbiedad, olor fétido y sedimentos acumulados procedentes de tuberías obsoletas.

Riesgo Sanitario y Dermatológico

Uso doméstico de agua con altos sólidos disueltos causa irritaciones cutáneas, dermatitis y afecciones estomacales por la inestabilidad de cloración en las redes locales.

Opacidad Informativa

Falta de sensores de libre acceso para los vecinos. AquaGuard permite constatar con rigor de datos si la calidad cumple con la Norma Oficial Mexicana NOM-127-SSA1.

Estrategia Epistemológica Doble Filtro: SIFT + CRAAP

Validación rigurosa de fuentes científicas, periodísticas (UDG, ITESO) e institucionales para sustentar denuncias públicas y reportes técnicos.

Código Firmware ESP32 (Arduino C++)

// AquaGuard IoT - ESP32 Main Firmware
// CUGDL - Universidad de Guadalajara
#include <WiFi.h>
#include <OneWire.h>
#include <DallasTemperature.h>

#define TURBIDITY_PIN 34
#define PH_PIN 35
#define ONE_WIRE_BUS 4

OneWire oneWire(ONE_WIRE_BUS);
DallasTemperature tempSensors(&oneWire);

void setup() {
  Serial.begin(115200);
  tempSensors.begin();
  pinMode(TURBIDITY_PIN, INPUT);
  Serial.println("AquaGuard IoT Node Initialized");
}

void loop() {
  int rawTurb = analogRead(TURBIDITY_PIN);
  float voltageTurb = rawTurb * (3.3 / 4095.0);
  float ntu = -1120.4 * (voltageTurb * voltageTurb) + 5742.3 * voltageTurb - 4352.9;
  if(ntu < 0) ntu = 0;

  tempSensors.requestTemperatures();
  float tempC = tempSensors.getTempCByIndex(0);

  Serial.print("Turbiedad: "); Serial.print(ntu); Serial.println(" NTU");
  Serial.print("Temperatura: "); Serial.print(tempC); Serial.println(" C");

  delay(2000);
}

Marco Epistemológico: SIFT + CRAAP

Método SIFT (Stop, Investigate, Find, Trace):

Detiene la desinformación al verificar reportes de redes sociales contra sensores calibrados en campo e investigaciones de la Universidad de Guadalajara e ITESO.

Test CRAAP (Currency, Relevance, Authority, Accuracy, Purpose):

Evalúa la vigencia de las muestras, la reputación de laboratorios consultados y la precisión técnica de los dispositivos IoT frente a estándares de la NOM-127-SSA1.
